# 🚀 منصة سكورا — Scora Platform (`FrontNew`)

منصة برمجية متكاملة لربط مطوري البرمجيات في مصر والوطن العربي بأصحاب الشركات والمشاريع، مع تقييم حقيقي للمهارات وتوثيق موثوقية التوظيف.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** Next.js 16 (App Router + Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Vanilla CSS Tokens
- **Database:** MySQL / MariaDB (Direct Connection Layer + Server Actions)
- **Auth & Security:** JOSE (JWT Sessions), BcryptJS, Server-Only Cookies

---

## ✅ الإصلاحات والتحسينات المكتملة (Completed Audit & Fixes)

### 1. 🛡️ الأمن والحماية (Security Hardening)
- **إلغاء ثغرة التمرير التلقائي (Fake Auth Bypass):** إزالة الـ `catch` blocks التي كانت تقوم بتسجيل الدخول الفوري أو إنشاء حساب وهمي للمستخدم في حال تعثر الاتصال بالسيرفر.
- **إلغاء تزوير الكوكيز (Cookie Forgery Fix):** قصر إنشاء وتحديث وحذف كوكيز الجلسات `scora_session` على السيرفر فقط (`createSession` / `destroySession`) وتجريد `setUserRole` في الـ Client من صلاحية تعديل الكوكيز.
- **تأمين تغيير كلمة المرور (IDOR Prevention):** ربط تغيير كلمة المرور بالجلسة الحالية الموثقة (`verifySession`) ومنع تمرير `userId` كباراميتر غير محمي.
- **تنظيف المفاتيح الحساسة:** إزالة المفاتيح والرموز السرية الافتراضية المكتوبة كودياً في الملفات التشغيلية.
- **إحكام مزامنة الجلسات (Session Sync):** حصر المزامنة اللحظية مع قاعدة البيانات `syncUserSessionWithDb()` على الـ JWT Token الموقّع فقط.

### 2. 📱 تدفق المستخدمين والإعداد (User Flow & Onboarding)
- **حقل رقم الموبايل:** إضافة حقل الموبايل المصري لصفحة التسجيل وتمريره وإجراء الفحص الأولي لصياغته.
- **مرونة حسابات العملاء:** إتاحة استخدام حساب العميل كفرد وصاحب عمل دون إلزامية إدخال اسم شركة.
- **نظام الإعداد الإجباري (Mandatory Onboarding Guard):** منع المطورين والعملاء الجدد من استخدام المنصة أو الوصول للشاشات الداخلية حتى إكمال بياناتهم الأساسية.
- **حظر صفحات الدخول للمسجلين:** توجيه المستخدمين المسجلين تلقائياً بعيداً عن `/login` و `/register` وحماية شاشات الإدارة `/admin`.

### 3. 🧹 تنظيف البيانات وقاعدة البيانات (Data Cleaning & MySQL Integration)
- **حذف البيانات الوهمية:** تفريغ كتل البيانات الافتراضية، الأسماء الوهمية، الرسوم البيانية المالية الثابتة، ودرجات السكورا غير الحقيقية.
- **الربط اللحظي بـ MySQL:** ربط القوائم والجلسات والشاشات بالمحتوى الفعلي المسجل في قاعدة بيانات MySQL.
