# 06 — Implementation Structure

The implementation is organized around a modular frontend/backend architecture:

```text
frontend/
├── public/
└── src/
    ├── components/
    ├── pages/
    ├── layouts/
    ├── hooks/
    ├── services/
    ├── assets/
    └── utils/

backend/
├── src/
│   ├── controllers/
│   ├── routes/
│   ├── services/
│   ├── models/
│   ├── middleware/
│   ├── utils/
│   └── config/
└── tests/
```

See the repository README for environment variables, setup, and run commands. Replace this note with the final implementation architecture once the code structure is complete.
