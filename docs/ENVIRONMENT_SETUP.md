# Scora V0.1 - دليل إعداد وتشغيل البيئة المحلية وقواعد البيانات (Environment Setup & Configuration Guide)

يوفر هذا الدليل خطوة بخطوة كافة التعليمات اللازمة لإعداد وتشغيل منصة Scora V0.1 على البيئة المحلية (Local Development Environment)، ربط قاعدة بيانات MySQL، وتشغيل سكربتات التحديث والأتمتة.

---

## 1. المتطلبات الأساسية للنظام (Prerequisites)

تأكد من تثبيت البرامج التالية على جهازك قبل البدء:

- **Node.js:** الإصدار 20.x LTS أو أحدث (يُفضل 20.11.0+)
- **Package Manager:** npm الإصدار 10.x أو أحدث
- **Database Engine:** MySQL 8.0+ أو MariaDB 10.5+
- **Git:** الإصدار 2.40+

للتحقق من الإصدارات المثبتة على جهازك:
```bash
node -v
npm -v
git --version
```

---

## 2. إعداد المتغيرات البيئية (Environment Variables)

قم بإنشاء ملف `.env.local` في الجذر الرئيسي للمشروع استناداً إلى `.env.example`:

```bash
cp .env.example .env.local
```

تأكد من ضبط المتغيرات الحقيقية الخاصة ببيئتك داخل ملف `.env.local`:

```ini
# ───────────────────────────────────────────────────────────────
# 1. إعدادات قاعدة البيانات (MySQL Connection)
# ───────────────────────────────────────────────────────────────
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=scora_db
DB_USER=root
DB_PASSWORD=your_secure_mysql_password
DB_CONNECTION_LIMIT=10

# ───────────────────────────────────────────────────────────────
# 2. إعدادات الجلسات والمصادقة (JWT Auth & Security)
# ───────────────────────────────────────────────────────────────
# مفتاح تشفير التوكين (يتم توليده بأمر node الموضح بالأسفل - 32 حرف على الأقل)
SESSION_SECRET=your_32_character_random_secret_key_here
SESSION_MAX_AGE_DAYS=7

# ───────────────────────────────────────────────────────────────
# 3. إعدادات محرك الذكاء الاصطناعي (OpenRouter AI Integration)
# ───────────────────────────────────────────────────────────────
OPENROUTER_API_KEY=sk-or-v1-your-openrouter-api-key
OPENROUTER_MODEL=anthropic/claude-3.5-sonnet

# ───────────────────────────────────────────────────────────────
# 4. إعدادات رفع الملفات (Upload Limits)
# ───────────────────────────────────────────────────────────────
MAX_UPLOAD_BYTES=5242880
```

> **ملاحظة أمنية مشددة:** ملف `.env.local` يحتوي على معلومات حساسة وسرية وهو محمي ومستبعد تلقائياً في `.gitignore` ولا يتم رفعه إطلاقاً للمستودع.

---

## 3. إعداد وتحديث قاعدة البيانات (Database Migrations)

يحتوي المشروع على سكربتات تحديث متتالية لتهيئة جداول MySQL وتحديث الهيكل.

قم بتشغيل السكربتات بالتتابع لإنشاء الجداول اللازمة:

```bash
# 1. تهيئة الجداول الأساسية (المستخدمين، المطورين، العملاء، المشاريع)
node scripts/migrate.js

# 2. تطبيق التحديثات المتقدمة حتى النسخة v8 (تقييم المطورين والـ AI)
node scripts/migrate-v8.js
```

للتحقق من سلامة الجداول واستقرار الاتصال بقاعدة البيانات:
```bash
node scripts/inspect-db.js
```

## 4. خطوات التثبيت والتشغيل المحلي (Installation & Run Steps)

### الخطوة الأولى: تثبيت الاعتمادات (Install Dependencies)
```bash
npm install --legacy-peer-deps
```

### الخطوة الثانية: تشغيل سيرفر التطوير المحلي (Start Dev Server)
```bash
npm run dev
```
سيكون التطبيق متاحاً على الرابط المحلي: `http://localhost:3000`

### الخطوة الثالثة: التحقق من صحة البناء والأنواع (Build Verification)
قبل رفع أي تعديلات، قم بتشغيل أمر البناء للتأكد من خلو المشروع من أي خطأ في Typescript أو البناء:
```bash
npm run build
```

---

## 5. التشغيل عبر GitHub Actions (CI/CD Pipeline)

عند رفع التعديلات على برانش `main` أو `Scora-V0.1`:
- يقوم خط أتمتة الـ CI (`.github/workflows/ci.yml`) بتشغيل الفحص الفني، فحص الأنواع، والتحقق من بناء كافة المسارات تلقائياً.
- تُستخدم متغيرات `secrets.SESSION_SECRET` و `secrets.DB_PASSWORD` المشفرة في إعدادات المستودع (GitHub Secrets) لتجنب كتابة أي بيانات سرية في الملفات المرفوعة.
