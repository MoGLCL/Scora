🔒 1. نموذج المصادقة والأمان (Security & Authentication Model)

تعتمد منصة Scora V0.1 على معمارية هجينة موثوقة لحماية البيانات والجلسات دون الحاجة لتخزين جلسات ثقيلة في الـ Memory:

المعيار (Mechanism) التقنية المستعملة الوصف وآلية الحماية
Stateless Sessions JOSE (HS256 JWT) تخزين توكين الجلسة المشفر في HTTP-Only Cookies يمنع الوصول إليها عبر JavaScript.
Server Actions Security lib/dal.ts verifySession() فحص صلاحية المستخدم ورتبته (developer / client / admin) قبل تنفيذ أي استعلام في السيرفر.
Data Validation Zod Schemas فحص هيكل ونوع البيانات المدخلة قبل معالجتها لمنع ثغرات الحقن (SQL & Injection).

⚙️ 2. خوادم العمليات المباشرة (Server Actions Reference)

خوادم العمليات تُنفذ مباشرة في سيرفر Next.js 16 وتضمن منع تسريب مفاتيح وقواعد البيانات.

أ. خوادم المصادقة والحسابات (Auth Actions)

registerAction(formData: FormData) lib/actions/auth.ts

إنشاء حساب جديد كمطور أو عميل، تشفير كلمة المرور بـ BcryptJS، وإنشاء جلسة JWT مشفرة.

المدخلات: email, password, full_name, role ('developer' | 'client')

loginAction(formData: FormData) lib/actions/auth.ts

التحقق من صحة بيانات الدخول وتعيين كوكيز الجلسة والتوجيه التلقائي للوحة التحكم.

ب. إكمال الملف الشخصي والمشاريع (Profile & Projects)

completeDeveloperOnboarding(data: DeveloperProfileInput) lib/actions/profile.ts

حفظ المسمى الوظيفي والمهارات والروابط المرجعية للمطور وتحويل حسابه لمرحلة اختبار الذكاء الاصطناعي.

createProjectAction(data: ProjectInput) lib/actions/profile.ts

نشر مشروع برمجي جديد في سوق المشاريع وتحديد الميزانية وسقف التنفيذ عبر العملاء.

submitProposalAction(data: ProposalInput) lib/actions/proposals.ts

تقديم عرض برمجي من مطور معتمد على أحد المشاريع المعلنة.

ج. محرك التقييم بالذكاء الاصطناعي (AI Assessment Engine)

startAssessmentSession() lib/actions/developer-assessment.ts

توليد أسئلة اختبار تفاعلية مخصصة عبر OpenRouter API Engine (Claude 3.5 Sonnet / GPT-4.1) وتجهيز الجلسة.

submitAnswerAction(sessionPublicId, questionPublicId, answerText) lib/actions/developer-assessment.ts

تحليل وتقييم إجابة المطور لحظياً بواسطة الـ AI وتحديث نقاط الـ SP ودرجة الموثوقية (Trust Score).

د. خدمات لوحة الإدارة والأدمن (Admin Actions)

reviewDeveloperAction(developerId, decision, reason) lib/actions/admin.ts

اعتماد أو رفض طلب انضمام مطور من لوحة الإدارة بعد الاطلاع على نتائج تقييم الذكاء الاصطناعي.

🌐 3. مسارات الـ REST API Endpoints (`app/api/*`)

جدول تفصيلي بمسارات الـ APIs المتاحة للتكامل الخارجي والتطبيقات التفاعلية.

المسار (Endpoint Route) النوع (Method) الصلاحية (Access Level) الوصف والتفاصيل
/api/admin/stats GET Admin Only استرجاع إحصائيات المنصة (عدد المستخدمين، المشاريع، متوسط درجات السكورا).
/api/admin/developers GET Admin Only جلب قائمة المطورين مع فلترة حالة الاعتماد ودرجة الموثوقية.
/api/admin/settings GET / POST Admin Only قراءة وتحديث إعدادات نموذج OpenRouter AI الافتراضي.
/api/developer-assessment/session POST Developer بدء جلسة تقييم تفاعلية بالذكاء الاصطناعي.
/api/developer-assessment/submit POST Developer تقديم الإجابات الفنية وتقييمها.
/api/notifications GET / PATCH Auth User استرجاع الإشعارات وتحديدها كـ Read.
/api/analytics GET Admin Only سجل تحليلات الزيارات وأداء المنصة.

💻 4. أمثلة الاستدعاء البرمجي (Call Examples)

أ. استدعاء REST API عبر JavaScript (fetch)

// جلب إحصائيات الأدمن مع إرسال الكوكيز المشفرة تلقائياً
const response = await fetch('/api/admin/stats', {
  method: 'GET',
  headers: {
    'Content-Type': 'application/json'
  }
});
const data = await response.json();
console.log('Admin Stats:', data);

ب. استدعاء Server Action مباشرة في React Server Component

import { startAssessmentSession } from '@/lib/actions/developer-assessment';

export default async function AssessmentStarter() {
  const result = await startAssessmentSession();
  if (result.success) {
    console.log('Session Public ID:', result.sessionPublicId);
  }
}
